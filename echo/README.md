# Echo ✨

צ'אט מעוצב שמבוסס על Claude: שיחות נשמרות, יצירת תמונות, צירוף תמונות ו-4 ערכות צבעים (פנינה ורודה, מים, ירקן ולילה).

## הפעלה

```bash
cd echo
pip install -r requirements.txt
python server.py
```

אחר כך פותחים בדפדפן: http://localhost:8000

## מפתחות API

בלי מפתחות, Echo עובד ב**מצב דמו**: התשובות מוכנות מראש והתמונות הן תמונות דמו, אבל הממשק כולו עובד.

כדי לחבר אותו באמת:

1. מעתיקים את `.env.example` לקובץ חדש בשם `.env`
2. ממלאים:
   - `ANTHROPIC_API_KEY` בשביל הצ'אט (מ-https://console.anthropic.com)
   - `OPENAI_API_KEY` בשביל יצירת תמונות (מ-https://platform.openai.com)
3. מפעילים מחדש את `python server.py`

הקובץ `.env` לא עולה ל-GitHub, כך שהמפתחות נשארים פרטיים.

## מה יש בפנים

| קובץ | מה הוא עושה |
| --- | --- |
| `server.py` | השרת: שמירת שיחות (SQLite), חיבור ל-Claude, יצירת תמונות |
| `static/index.html` | מבנה הדף |
| `static/style.css` | כל העיצוב וערכות הצבעים |
| `static/app.js` | ההתנהגות: שליחה, סטרימינג, היסטוריה, תמונות |
| `data/` | נוצר אוטומטית: מסד הנתונים והתמונות (לא עולה ל-GitHub) |

## איך עובדת יצירת תמונות

כשמבקשים ציור ("תצייר לי חתול מהמם עם אסטרונאוט"), Claude מבין לבד שזו בקשה לתמונה. הוא כותב תיאור מפורט ושולח אותו לשירות התמונות, ותמונה אחת חוזרת ישר לתוך השיחה.
